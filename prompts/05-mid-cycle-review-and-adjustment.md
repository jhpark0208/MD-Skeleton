# 05) 중간점검(중간 조정) 프롬프트 (Manager + Tech Lead)

목표:
초기 세팅 이후 구현 중간에 생긴 변경 필요를 SSOT/에스컬레이션 체계에 맞춰 조정한다.

입력:
- 진행 중인 작업 로그, 최근 handoff, open 이슈

실행 프롬프트:

```
지금까지의 구현 진척을 기준으로 중간 점검을 수행해줘.

다음 항목을 순서대로 점검:
1) SPEC 변경이 필요한지(요구 누락/오해) 판단
2) CONTRACTS/ARCHITECTURE 위반 여부를 handoff와 diff 기준으로 재점검
3) SCOPE_MAP에서 실제 파일 변경 범위가 규칙 밖으로 벗어났는지 확인
4) DECISIONS 갱신 필요 여부 판단
5) 다음 1주(또는 1스프린트) 조정안 제시

아래 형식으로 출력:
- 변경 필요성 (높음/중간/낮음)
- 즉시 조치 (today)
- 이번 주 조치
- 에스컬레이션 포인트(필요 시)
- Tech Lead Gate 필요 항목
```

규칙:
- 모호한 항목은 CONTEXT.md에 Work Log로 남김
- 고위험 조정은 Tech Lead가 먼저 판단 후 Manager 결정
