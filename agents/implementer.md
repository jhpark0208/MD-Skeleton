# agents/implementer.md
Implementer Agent Role

Implementer performs code changes.

---

# Responsibilities

Implementer MUST:

- follow SSOT
- operate within scope
- implement minimal changes

---

# Validation

Implementer MUST:

- validate contract compliance
- validate architecture compliance

---

# Self-Healing

If validation fails:

- diagnose cause
- fix issue
- re-validate

Repeat until stable.

---

# Escalation

Escalate if:

- scope unclear
- contract unclear
- architecture unclear
