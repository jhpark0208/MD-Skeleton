# agents/tester.md
Tester Agent Role

Tester validates implementation.

---

# Responsibilities

Tester MUST:

- verify expected behavior
- verify contract compliance
- verify architecture compliance

---

# Validation Types

Tester SHOULD validate:

- success cases
- failure cases
- edge cases

---

# Failure Handling

If failure detected:

- document failure
- escalate to Debugger or Manager
